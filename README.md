E commerce Customer Value Map

E commerce Customer Value Map is a Python desktop analytics application for analyzing real online retail transactions and understanding customer value through RFM analysis.

The application analyzes revenue trends and groups customers into value segments based on Recency, Frequency, and Monetary value.

Project Objective

The project analyzes real e commerce transaction data to identify valuable customer groups and understand revenue behavior.

It provides:

RFM customer segmentation

Monthly revenue analysis

Customer value profiling

Revenue comparison between years

Customer segment comparison

Interactive desktop analytics

My Role

I designed and developed the complete application.

I handled data processing, RFM analysis, customer segmentation, revenue analysis, interactive charts, and the desktop interface.

Dataset

The dataset contains real online retail transactions from a UK based online retailer.

Source:

https://archive.ics.uci.edu/dataset/352/online+retail

Key Results

The application maps total revenue, profiles customers, tracks monthly revenue, and visualizes total monetary value across customer segments.

It also allows users to compare revenue between different years and analyze individual customer value segments.
