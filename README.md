# E-commerce Customer Value Map

A Tkinter desktop application for understanding customer value in real online-retail transactions. It maps monthly revenue and RFM-based customer segments in a native Windows interface.

## Run on Windows

بعد فك الضغط، اضغط مرتين على ملف `run.bat` وسيتم تثبيت المتطلبات وتشغيل التطبيق تلقائيًا. أو شغّله من PowerShell:

```powershell
py -m pip install -r requirements.txt
py app.py
```

## Skills shown

Python, Tkinter, Pandas, Matplotlib, RFM analysis, customer segmentation, revenue analytics, and desktop UI design.

## Data

The included outputs are derived from the UCI Online Retail dataset.

Source: https://archive.ics.uci.edu/dataset/352/online+retail
